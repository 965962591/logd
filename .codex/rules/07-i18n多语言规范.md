# i18n 多语言规范

## 适用范围

本规则覆盖 `crates/logd/src/` 的菜单、标题栏、Dock、工具栏、过滤器面板、快捷键提示、状态、错误和空状态。当前语言固定为简体中文 `zh-CN` 与英文 `en-US`；日志正文、文件名、路径、过滤器文本和用户输入属于数据，不翻译。

## 规则条目

### R1: 用户可见文本必须使用消息 key
**断言**：UI 代码不得直接写中文或英文显示字符串；所有菜单、按钮、tooltip、错误和状态必须通过 `crate::i18n::text("key")` 或 `text_args` 获取，数据内容不适用此规则。
**示例**：
```rust
use crate::i18n::text;

Button::new("open").label(text("file.open"))
```
**违规特征**：在 `toolbar.rs` 写 `.child("打开文件")`，或错误分支直接拼接英文句子。

### R2: 语言资源路径和 key 集合固定
**断言**：语言资源必须位于 `crates/logd/locales/zh-CN.toml` 与 `crates/logd/locales/en-US.toml`；两文件 key 集合必须完全一致；key 使用小写点分层格式。
**示例**：
```text
crates/logd/locales/
  zh-CN.toml
  en-US.toml
```
```toml
# zh-CN.toml / en-US.toml 均必须存在
[file]
open = "..."
[titlebar]
close = "..."
```
**违规特征**：把翻译散落在 `app.rs`，或只给中文增加 `filter.save` 而英文文件没有同名 key。

### R3: 语言选择与回退策略唯一
**断言**：语言优先级必须为用户设置 > 系统 locale > `zh-CN`；不支持的 locale 先按语言前缀回退；缺失 key 回退到 `en-US`，仍缺失时显示 key 本身并记录诊断，不得 panic 或显示空字符串。
**示例**：
```rust
pub fn resolve_locale(user: Option<&str>, system: &str) -> Locale {
    user.map(Locale::parse)
        .or_else(|| Locale::parse(system).ok())
        .unwrap_or(Locale::ZhCn)
}

pub fn text(key: &str) -> String {
    current().get(key)
        .or_else(|| fallback_en().get(key))
        .unwrap_or_else(|| key.to_owned())
}
```
**违规特征**：不同组件各自检测 locale，或翻译缺失时返回空字符串造成按钮不可见。

### R4: 参数化消息禁止拼接句子
**断言**：包含路径、行号、数量、百分比或错误原因的用户可见文本必须使用带命名参数的模板；业务代码不得拼接中英文句子，参数值不得参与 key 查找。
**示例**：
```toml
[status]
matched_lines = "命中 {count} 行"
open_failed = "无法打开 {path}: {reason}"
```
```rust
text_args("status.open_failed", [
    ("path", path.display().to_string()),
    ("reason", error.to_string()),
]);
```
**违规特征**：`format!("Matched {} lines", count)` 直接作为 UI 文本，或把路径拼进消息 key。

### R5: 菜单、标题栏和 Dock key 必须完整覆盖
**断言**：资源必须至少包含文件菜单 open/refresh/recent、视图菜单 show_all/show_only_filtered/show_filters、过滤器菜单 add/edit/delete/save、标题栏窗口控制、Dock 状态、选择/复制/编辑和异步状态的双语 key。
**示例**：
```toml
[file]
open = "..."
refresh = "..."
recent = "..."
[view]
show_all = "..."
show_only_filtered = "..."
show_filters = "..."
[filter]
add = "..."
edit = "..."
delete = "..."
save = "..."
```
**违规特征**：新增“显示过滤器”菜单却没有 tooltip key，或 Dock 悬浮/停靠状态只显示中文。

### R6: 双语资源和布局必须自动校验
**断言**：每次 UI 变更必须执行资源 key 集合、参数占位符和格式解析检查，并在 `zh-CN`、`en-US` 两种语言下完成 GPUI 启动、菜单、标题栏、打开、筛选、编辑、错误和空状态冒烟；按钮文本不得裁切或溢出。
**示例**：
```text
cargo test -p logd -- i18n
GPUI smoke: zh-CN 启动/标题栏/菜单/Dock/错误
GPUI smoke: en-US 启动/标题栏/菜单/Dock/错误
```
**违规特征**：只验证中文界面，英文界面出现 key 原文、参数未替换或菜单文字遮挡搜索框。
