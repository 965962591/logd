# 核心铁律与避坑

## 适用范围

本规则覆盖 50GB 级日志的存储、索引、匹配、筛选、虚拟滚动、编辑、并发、编码和桌面 UI 交互。

## 规则条目

### R1: 禁止整文件或全量行对象入堆
**断言**：日志正文必须通过 `memmap2` 映射；任何路径不得构造每行一个 `String`、全量行文本数组或长度等于总行数的偏移数组；50GB 文件引擎堆内存目标低于 300MB，不含 OS page cache。
**示例**：
```rust
let source = FileSource::open(path)?;
let index = LineIndex::build_full(source.data(), &progress);
```
**违规特征**：`std::fs::read(path)?.lines().map(str::to_owned).collect()`，或生成 5 亿个 `u64` 偏移。

### R2: 全局坐标和滚动位置使用 u64
**断言**：文件字节偏移、总行数、原始行号、筛选命中行号和 `anchor_line` 必须使用 `u64`；`f32` 只能表示视口内像素偏移和最终绘制像素。
**示例**：
```rust
pub struct Viewport {
    pub anchor_line: u64,
    pub pixel_offset: f32,
}

let ratio = anchor_line as f64 / total_lines.max(1) as f64;
```
**违规特征**：`let scroll_y = line as f32 * 18.0`，或把 5 亿行映射成一个 GPUI `f32` 总高度。

### R3: 稀疏索引必须按整行边界构建
**断言**：行索引必须使用 `ANCHOR_STRIDE = 1024` 的块内锚点；`build_head` 必须通过 `indexed_bytes`/`complete` 标识部分结果；块边界不得把半行计入可见数据。
**示例**：
```rust
pub const ANCHOR_STRIDE: u64 = 1024;
let start = index.line_start(source.data(), requested_line);
```
**违规特征**：按固定字节切块后直接把切片起点当作新行，或在索引未完成时隐藏行数的不确定性。

### R4: 匹配在原始字节上完成，解码只用于可见行
**断言**：筛选必须使用 `AhoCorasick` 与 `regex::bytes` 作用于 mmap 原始 bytes；只有视口可见的约 60 行允许解码；编码探测顺序必须是 BOM、UTF-8、GB18030，UTF-16 必须报错。
**示例**：
```rust
let matcher = MatcherSet::new(filters, source.encoding())?;
let visible = matcher.is_visible(&data[start as usize..end as usize]);
let text = source.decode(start, end);
```
**违规特征**：为了匹配先把 50GB 转换成 Unicode `String`，或使用系统默认编码静默读取中文日志。

### R5: include/exclude 与重叠匹配语义不可改变
**断言**：可见性必须满足“无 include 或命中 include，且未命中 exclude”；字面量匹配必须使用 `find_overlapping_iter` 与 `MatchKind::Standard`；CRLF 的 `\r` 不得成为显示内容；无末尾换行的最后一行也必须扫描。
**示例**：
```rust
let visible = (no_include || include_hit) && !exclude_hit;
for m in ac.find_overlapping_iter(line) {
    spans.push(Span { start: m.start(), end: m.end(), filter: map[m.pattern().as_usize()] });
}
```
**违规特征**：使用非重叠 `find_iter` 导致 `abc`/`bcd` 在 `abcd` 中漏报，或把 excluding 过滤器错误当成 include。

### R6: 后台任务必须可取消且不触碰 UI
**断言**：索引和筛选必须复用 chunk、使用 rayon，并通过独立 `Arc<Progress>` 报告进度；worker 至少每 4096 行检查取消；worker 不得直接调用 `Window`、`Entity` 或组件方法。
**示例**：
```rust
let progress = Arc::new(Progress::default());
let outcome = scan_all(data, &index, &matcher, &progress);
if progress.is_cancelled() {
    return TaskResult::Cancelled;
}
```
**违规特征**：取消后仍发布完成状态，或让 rayon 闭包捕获 `&mut Window`。

### R7: 只渲染视口行，编辑必须受控
**断言**：`log_view.rs` 每帧只读取可见行加 2 行缓冲；单行默认最多渲染 4096 字符；鼠标选择只保存选区坐标，编辑操作必须写入显式编辑缓冲区并通过用户命令保存，不得修改只读 mmap。
**示例**：
```rust
let visible_count = (viewport_height / line_height).ceil() as usize + 2;
let selection = Selection { anchor: start, active: end };
```
**违规特征**：用 `children()` 创建数亿行元素、复制整份日志作为编辑状态，或直接通过裸指针写 mmap。

### R8: 标题栏和 Dock 不能阻塞日志任务
**断言**：自绘标题栏、菜单、搜索框和 Dock 布局只更新 UI Entity；窗口拖动、最小化、最大化、关闭、悬浮/停靠操作不得同步等待索引或筛选；后台任务运行时取消和窗口控制必须仍可响应。
**示例**：
```rust
self.dock_layout = DockLayout::Docked { side: DockSide::Right };
cx.notify();
```
**违规特征**：点击菜单后在 UI 线程执行全文件扫描，或 Dock 切换导致日志视口停止响应。
