# 技术栈与核心库

## 适用范围

本规则锁定 `D:\tuning\tools\AE\logd` 的 Cargo workspace、Rust 工具链、GPUI UI、日志引擎依赖、平台目标和发布边界。

## 规则条目

### R1: Cargo workspace 与 Rust 版本固定
**断言**：根 `Cargo.toml` 必须保持 `resolver = "2"`、workspace members 为 `crates/logd-core` 与 `crates/logd`、`edition = "2021"`、`rust-version = "1.85"`；CI 基线使用 `cargo/rustc 1.96.0`。
**示例**：
```toml
[workspace]
resolver = "2"
members = ["crates/logd-core", "crates/logd"]

[workspace.package]
edition = "2021"
rust-version = "1.85"
```
**违规特征**：新增 crate 使用 Edition 2024，或在未升级 MSRV 的情况下使用 nightly-only API。

### R2: GPUI 与 Longbridge 组件库来源固定
**断言**：UI 必须使用 Zed Git 的 `gpui` 0.2.2 与 `gpui_platform` 0.1.0（rev `d7b9b38584cdb1e778a781548d32da35b2be1e96`），以及 Longbridge Git 的 `gpui-component` 0.5.2 和 assets 0.5.1（rev `f517e74849c1e676bb03af90266e8449d01344f5`）；代码 import 名称必须是 `gpui_component`。需求中的“gpui-kit”统一指该 Longbridge `gpui-component`，不得引入另一同名 crate。
**示例**：
```toml
[workspace.dependencies]
gpui = { git = "https://github.com/zed-industries/zed", rev = "d7b9b38584cdb1e778a781548d32da35b2be1e96" }
gpui_platform = { git = "https://github.com/zed-industries/zed", rev = "d7b9b38584cdb1e778a781548d32da35b2be1e96", features = ["font-kit"] }
gpui-component = { git = "https://gh-proxy.org/https://github.com/longbridge/gpui-component", rev = "f517e74849c1e676bb03af90266e8449d01344f5" }
gpui-component-assets = { git = "https://gh-proxy.org/https://github.com/longbridge/gpui-component", rev = "f517e74849c1e676bb03af90266e8449d01344f5" }
```
```rust
use gpui_component::{h_flex, v_flex, Root};
```
**违规特征**：使用 `use gpui_kit::...` 指向未知包，或让 Zed 依赖通过 gh-proxy，导致依赖图出现两份 GPUI。

### R3: 核心引擎依赖版本基线固定
**断言**：直接依赖基线为 `anyhow 1.0.102`、`thiserror 2.0.18`、`memchr 2.8.0`、`memmap2 0.9.11`、`aho-corasick 1.1.4`、`regex 1.12.3`、`rayon 1.12.0`、`quick-xml 0.36.2`、`encoding_rs 0.8.35`、`parking_lot 0.12.5`、`dirs 6.0.0`；升级必须记录原因并更新 Cargo.lock。当前 Cargo.lock 已解析出部分更高兼容版本，落实精确锁定前不得把清单解析结果误写成直接依赖基线。
**示例**：
```toml
[workspace.dependencies]
memmap2 = "=0.9.11"
memchr = "=2.8.0"
aho-corasick = "=1.1.4"
regex = "=1.12.3"
rayon = "=1.12.0"
quick-xml = "=0.36.2"
encoding_rs = "=0.8.35"
```
**违规特征**：在单个 crate 中重新声明 `memmap2 = "0.8"`，或使用未解释的 `*` 版本替代 workspace 基线。

### R4: 四个桌面目标必须可检查
**断言**：发布与 CI 必须覆盖 `x86_64-pc-windows-msvc`、`aarch64-pc-windows-msvc`、`x86_64-apple-darwin`、`aarch64-apple-darwin`；平台专属依赖必须使用 target 条件，`logd-core` 不得无条件引入 Windows/macOS API。
**示例**：
```text
cargo check --workspace --target x86_64-pc-windows-msvc
cargo check --workspace --target aarch64-pc-windows-msvc
cargo check --workspace --target x86_64-apple-darwin
cargo check --workspace --target aarch64-apple-darwin
```
**违规特征**：在 `logd-core/Cargo.toml` 普通 dependencies 中添加 `windows`、`cocoa` 或 `metal`。

### R5: GPUI feature 与窗口后端按平台验证
**断言**：Windows 必须验证 DirectX/DirectWrite 路径，macOS 必须验证 Metal/Blade 路径；新增 GPUI feature 必须在四个 target 至少完成 `cargo check`，不得无条件打开 wayland 或 x11。
**示例**：
```toml
[target.'cfg(target_os = "windows")'.dependencies.gpui]
git = "https://github.com/zed-industries/zed"
rev = "d7b9b38584cdb1e778a781548d32da35b2be1e96"
features = ["windows-manifest"]
```
**违规特征**：只检查单个平台就声称自绘标题栏与 Dock 跨平台可用。

### R6: 发布边界是纯本地原生应用
**断言**：发布产物是 Windows/macOS 原生便携式二进制；日志、`.tat`、设置和 Dock 布局只读写本地文件，不引入 HTTP、WebSocket、Tauri IPC、SQLite、云同步或运行时下载资源。
**示例**：
```text
logd.exe
logd
D:\tuning\tools\AE\logd\tat\ae_log.tat
```
**违规特征**：新增 `reqwest`、WebSocket client 或远程服务来保存过滤器。

### R7: 依赖图和性能验证必须可复现
**断言**：每次依赖更新后必须检查 Cargo.lock 中 Git URL、commit 和版本唯一性；涉及索引、匹配、渲染或并发时必须使用 `crates/logd-core/examples/gen_big_log.rs` 记录首屏、索引、筛选耗时及 RSS。
**示例**：
```text
rg -n 'source = "git\+|name = "gpui|name = "gpui-component' Cargo.lock
cargo run --release -p logd-core --example gen_big_log -- 10 D:/tmp/logd-big.log
```
**违规特征**：Cargo.lock 出现两份不兼容的 gpui source，或只用 KB 夹具宣称满足 50GB 性能目标。
