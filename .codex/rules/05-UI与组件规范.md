# UI 与组件规范

## 适用范围

本规则覆盖 `crates/logd/src/` 的 Git 版 GPUI、Longbridge `gpui-component`、无边框窗口、自绘标题栏、菜单栏、搜索、标签页、日志视口、过滤器面板和 Dock 布局。

## 规则条目

### R1: 基础控件优先使用 Longbridge gpui-component
**断言**：按钮、输入框、菜单、Tooltip、Tabs、Dialog、Checkbox、Dock 等基础控件必须优先使用锁定版本的 `gpui_component`；只有日志虚拟视口、自绘滚动条和日志高亮允许业务自绘；组件缺失时，适配层必须放在 `crates/logd/src/ui/components/` 并写明缺口。
**示例**：
```rust
use gpui_component::button::Button;
use gpui_component::input::{Input, InputState};
use gpui_component::{h_flex, v_flex, Root};
```
**违规特征**：在 `menu_bar.rs` 手写通用菜单状态机，或引入另一个名为 `gpui-kit` 的 crate。

### R2: 所有颜色必须来自语义设计令牌
**断言**：UI 业务代码不得直接出现十六进制颜色、RGB 字面量或裸 `gpui::rgb()`；所有颜色必须经过 `crates/logd/src/ui/theme.rs` 的令牌映射，至少包含 `bg-background`、`bg-surface`、`bg-surface-elevated`、`fg-foreground`、`fg-muted`、`border-default`、`accent-primary`、`selection`、`status-error`、`status-warning`、`log-line-number`。
**示例**：
```rust
pub enum ColorToken { BgBackground, BgSurface, Selection, AccentPrimary }

pub const fn color(token: ColorToken) -> u32 {
    match token {
        ColorToken::BgBackground => 0x1E1E1E,
        ColorToken::BgSurface => 0x252526,
        ColorToken::Selection => 0x264F78,
        ColorToken::AccentPrimary => 0x4FC1FF,
    }
}

div().bg(rgb(color(ColorToken::BgSurface)))
```
**违规特征**：在 `tabs.rs` 写 `rgb(0xff0000)`，或在标题栏与日志视图使用不同的同义背景常量。

### R3: 无边框窗口必须由自绘标题栏完整接管
**断言**：窗口创建必须使用无系统装饰选项；`crates/logd/src/ui/title_bar.rs` 必须渲染应用名、可拖动区域、最小化/最大化/关闭按钮，并通过 `platform.rs` 提供窗口控制；不得继续把 `TitleBar::window_options()` 作为唯一窗口实现。
**示例**：
```rust
// crates/logd/src/platform.rs
pub fn window_options() -> WindowOptions {
    WindowOptions {
        titlebar: Some(TitlebarOptions { appears_transparent: true, ..Default::default() }),
        ..Default::default()
    }
}
```
```rust
// crates/logd/src/ui/title_bar.rs
h_flex()
    .child(div().flex_1().on_mouse_down(MouseButton::Left, begin_window_drag))
    .child(icon_button("minimize").tooltip(text("titlebar.minimize")))
    .child(icon_button("maximize").tooltip(text("titlebar.maximize")))
    .child(icon_button("close").tooltip(text("titlebar.close")))
```
**违规特征**：系统标题栏仍显示默认标题，或关闭按钮的点击区域覆盖搜索输入。

### R4: 标题栏搜索与顶部菜单布局固定
**断言**：标题栏必须使用三段式布局：左侧应用与菜单区，中间固定宽度且水平居中的全局搜索输入，右侧窗口控制区；“文件”“视图”“过滤器”必须是同一 `menu_bar.rs` 命令模型的一级菜单。搜索输入不得回退到普通工具栏左侧。
**示例**：
```rust
h_flex()
    .child(div().flex_1().child(menu_button(text("menu.file"))))
    .child(div().w(px(360.)).child(Input::new(&self.keyword).small()))
    .child(div().flex_1().justify_end().child(window_controls))
```
```rust
enum MenuCommand { Open, Refresh, RecentFiles, ShowAll, ShowOnlyFiltered, ShowFilters, AddFilter, EditFilter, DeleteFilter, SaveFilter }
```
**违规特征**：窗口宽度变化时搜索框偏离窗口中心，或菜单按钮直接执行不可测试的内联副作用。

### R5: 菜单命令必须覆盖指定行为
**断言**：“文件”菜单必须包含打开、刷新、最近文件；“视图”必须包含显示全部、仅显示过滤、显示过滤器，并为“显示过滤器”提供 tooltip；“过滤器”必须包含新增过滤器、编辑、删除、保存过滤器；每项必须映射到一个可测试的 `MenuCommand`。
**示例**：
```rust
MenuItem::new(text("file.open"))
    .on_click(cx.listener(|this, _, window, cx| this.dispatch(MenuCommand::Open, window, cx)))
    .tooltip(text("tooltip.file.open"));
```
**违规特征**：只有文本按钮没有菜单命令，或“刷新”仅重绘 UI 而不重新验证文件与索引状态。

### R6: 日志视口必须虚拟渲染且布局稳定
**断言**：`log_view.rs` 只渲染可见行加 2 行缓冲，位置使用 `anchor_line: u64 + pixel_offset: f32`；行号槽宽度、行高和滚动条轨道必须稳定；禁止用总行数乘行高创建单个巨大 f32 元素。
**示例**：
```rust
let rows = (viewport_height / theme::LINE_HEIGHT).ceil() as usize + 2;
index.line_spans(data, viewport.anchor_line, rows, &mut spans);
```
**违规特征**：`div().h(px(total_lines as f32 * 18.0))`，或文本长度变化引发行高和滚动条跳动。

### R7: 日志正文必须支持选择、复制和受控编辑
**断言**：日志正文必须支持鼠标拖选、键盘复制和选区高亮；编辑状态只能保存选区及被编辑行的增量缓冲，编辑后的内容必须通过显式保存命令写入新文件或用户选择的目标，不得改写 mmap 源文件；跨行选择必须保留原始文件行号。
**示例**：
```rust
pub struct Selection { pub anchor: TextPoint, pub active: TextPoint }
pub struct EditBuffer { pub file_line: u64, pub text: String, pub dirty: bool }
```
**违规特征**：日志行不能鼠标选择，或把完整 mmap 转成 `Vec<String>` 作为编辑器模型。

### R8: 过滤器面板与 Dock 状态完整可用
**断言**：`filter_panel.rs` 必须支持新增、编辑、删除、保存过滤器，并显示 enabled、include/exclude、regex、大小写、Line/Field、前景色/背景色；`dock.rs` 必须支持至少左/右/底部停靠与悬浮，布局状态由 Entity 管理并可持久化。
**示例**：
```rust
enum DockLayout { Docked { side: DockSide }, Floating { bounds: Bounds<Pixels> }, Hidden }

Button::new("save-filter")
    .label(text("filter.save"))
    .on_click(cx.listener(|this, _, _, cx| this.save_filter(cx)));
```
**违规特征**：过滤器只能点击开关不能编辑文本，或面板只能固定在顶部、重启即丢失位置。

### R9: 图标、tooltip 和状态反馈必须完整
**断言**：保存、关闭、刷新、取消、复制和窗口控制必须使用组件库/GPUI 图标按钮；不熟悉图标必须有 tooltip；危险或异步操作必须显示 disabled、进行中和失败状态。
**示例**：
```rust
icon_button("refresh")
    .tooltip(text("tooltip.refresh"))
    .disabled(self.indexing)
```
**违规特征**：用圆角文字矩形代替熟悉图标，或筛选运行中仍可重复提交相同任务。

### R10: 用户可见文本必须走 i18n
**断言**：菜单、标题栏、tooltip、状态、错误和空状态文本必须通过 `crate::i18n::text`/`text_args` 获取；日志正文、文件名、路径和用户输入保持原文；布局必须在 `zh-CN` 与 `en-US` 下均无裁切。
**示例**：
```rust
Button::new("open").label(text("file.open"));
div().child(text_args("status.matched_lines", [("count", count.to_string())]));
```
**违规特征**：在 `app.rs` 直接写“打开文件”或英文句子，或英文翻译缺失时显示空白。
