# 05-UI与组件规范

## 适用范围

本规则覆盖 crates/logd/src/ 下的 Git 版 GPUI（当前锁文件包版本 gpui 0.2.2）界面、Longbridge Git 版 `gpui-component`（当前锁文件包版本 0.5.2）组件、日志视口、标签页、筛选面板、工具栏、主题和 Windows/macOS 交互。

## 规则条目

### R1: gpui-kit 组件优先，业务视图不得复制基础控件

**断言**：按钮、文本输入、复选框、下拉菜单、Tabs、Dialog、Tooltip、Table 等基础交互必须优先使用当前锁定 Git commit 的 `gpui_component`；只有日志虚拟视口、自绘滚动条和过滤器高亮属于允许的业务定制。组件缺失时，包装层必须放在 `crates/logd/src/ui/components/` 并记录缺口原因。

**示例**：

~~~~rust
use gpui_component as gpui_kit;

// 基础控件由锁定版本的 gpui-component 提供。
// 日志正文仍由 ui/log_view.rs 自建视口渲染。
~~~~

**违规特征**：在 toolbar.rs 手写一套 Button 状态机，或用 div().on_click() 伪造可复用的输入框而没有组件缺口记录。

### R2: 所有颜色必须经过语义设计令牌

**断言**：UI 业务代码不得直接出现十六进制颜色、RGB 字面量或裸 gpui::rgb()；所有颜色必须来自 crates/logd/src/ui/theme.rs 的 ColorToken 映射。主题至少定义以下稳定令牌：bg-background=#1E1E1E、bg-surface=#252526、bg-surface-elevated=#2D2D30、fg-foreground=#D4D4D4、fg-muted=#858585、border-default=#3E3E42、accent-primary=#4FC1FF、selection=#264F78、status-error=#F14C4C、status-warning=#CCA700、log-line-number=#858585。

**示例**：

~~~~rust
// crates/logd/src/ui/theme.rs
#[derive(Clone, Copy)]
pub enum ColorToken {
    BgBackground,
    BgSurface,
    BgSurfaceElevated,
    FgForeground,
    FgMuted,
    BorderDefault,
    AccentPrimary,
    Selection,
    StatusError,
    StatusWarning,
    LogLineNumber,
}

pub const fn color(token: ColorToken) -> u32 {
    match token {
        ColorToken::BgBackground => 0x1E1E1E,
        ColorToken::BgSurface => 0x252526,
        ColorToken::BgSurfaceElevated => 0x2D2D30,
        ColorToken::FgForeground => 0xD4D4D4,
        ColorToken::FgMuted => 0x858585,
        ColorToken::BorderDefault => 0x3E3E42,
        ColorToken::AccentPrimary => 0x4FC1FF,
        ColorToken::Selection => 0x264F78,
        ColorToken::StatusError => 0xF14C4C,
        ColorToken::StatusWarning => 0xCCA700,
        ColorToken::LogLineNumber => 0x858585,
    }
}
~~~~

~~~~rust
use crate::ui::theme::{color, ColorToken};

div().bg(rgb(color(ColorToken::BgBackground)))
~~~~

**违规特征**：在 tabs.rs 写 rgb(0xff0000)，或在同一组件中直接混用背景色和前景色常量。

### R3: 日志视口必须采用稳定尺寸和虚拟渲染

**断言**：log_view.rs 必须只渲染 viewport 可见行加 2 行缓冲，并使用 anchor_line: u64 + pixel_offset: f32；scrollbar.rs 必须用 u64 计算滑块比例后在最后一步转换像素。不得把总行数映射为单个 f32 高度。

**示例**：

~~~~rust
pub struct LogViewport {
    pub anchor_line: u64,
    pub pixel_offset: f32,
    pub line_height: f32,
    pub h_scroll: f32,
}

let rows = (viewport_height / state.line_height).ceil() as usize + 2;
~~~~

**违规特征**：使用 div().h(px(total_lines as f32 * 18.0))，或因文本长度变化让行高、行号槽宽度和滚动条轨道发生布局抖动。

### R4: 日志行布局和高亮优先级固定

**断言**：每行必须按“右对齐原始行号槽 + 内容”布局；Field 模式只渲染 flatten_spans 后的区间，Line 模式将过滤器样式应用于整行；重叠命中按过滤器列表顺序由前到后优先。超长内容默认截断到 4096 字符。

**示例**：

~~~~rust
div()
    .flex()
    .child(line_number_slot)
    .child(content_view)
~~~~

**违规特征**：仅显示筛选结果时把命中数组下标当行号，或让后面的过滤器覆盖列表前面过滤器的颜色。

### R5: 操作控件使用明确图标、tooltip 和状态

**断言**：保存、关闭、刷新、取消、水平滚动等熟悉操作必须使用 `gpui_component`/GPUI 图标按钮；不熟悉图标必须有 tooltip；危险操作必须展示禁用、进行中、失败三种状态。只有“打开文件”“另存为”等不可替代命令可使用图标加文字。

**示例**：

~~~~rust
let cancel_button = icon_button("x")
    .tooltip("取消当前索引或筛选任务")
    .disabled(!task_running);
~~~~

**违规特征**：使用“关闭”“取消”等圆角文字矩形代替常见图标，或按钮点击后没有 loading/disabled 反馈。

### R6: 标签页和筛选面板状态必须可扫描

**断言**：顶部标签栏必须显示文件名、活动态、关闭入口和全路径 tooltip；筛选面板必须显示启用状态、include/exclude、正则、大小写、Line/Field 模式以及前景/背景色；所有用户可见文本必须通过 `07-i18n多语言规范.md` 的消息 key 获取。面板控件不得把完整日志内容复制到自身状态。

**示例**：

~~~~rust
struct FilterRowView {
    filter_index: usize,
    enabled: bool,
    excluding: bool,
    regex: bool,
    case_sensitive: bool,
    mode: HighlightMode,
}
~~~~

**违规特征**：filter_panel.rs 为每条过滤器保存一个全量日志快照，或标签标题只显示“文档 1”而没有文件名和路径提示。

### R7: Windows/macOS 快捷键和文件操作统一抽象

**断言**：Ctrl+O、Ctrl/Cmd+Tab、Ctrl/Cmd+G、Ctrl/Cmd+Home/End 必须通过 `platform.rs` 的主修饰键抽象；文件对话框优先使用 gpui-component 提供的组件，若当前 Git 版本没有对应能力才允许引入并锁定 `rfd 0.16.0`，且必须通过同一适配函数返回路径。

**示例**：

~~~~rust
pub enum PrimaryModifier {
    Control,
    Command,
}

pub fn open_file_dialog() -> Option<std::path::PathBuf> {
    // Windows/macOS 使用相同的上层接口
    rfd::FileDialog::new().pick_file()
}
~~~~

**违规特征**：在 macOS 仍绑定 Ctrl+O，或在多个组件分别调用平台原生文件 API。

### R8: 加载、空结果、错误和取消状态必须可见

**断言**：打开、索引、筛选、取消、空文件、筛选无命中、编码不支持、文件映射失败都必须有界面状态；后台任务运行时主视图仍可响应取消和窗口操作。

**示例**：

~~~~rust
enum DocumentStatus {
    Loading { fraction: f32 },
    Ready,
    Empty,
    NoMatches,
    Cancelled,
    Error(String),
}
~~~~

**违规特征**：筛选无命中时渲染空白区域却没有“0 条命中”状态，或索引期间冻结整个窗口。
